# melite-utility-nodes

shared utility nodes.

Tech Noir utility nodes for ComfyUI.

## Nodes

- `GLBLoader`
- `GLBPreview`
- `HYMotionModelDir`
- `KimodoModelDir`
- `MotionPreview`
- `SeeThroughModelDir`
- `TypedModelDir`

## Install

```bash
cd /path/to/ComfyUI/custom_nodes
git clone https://github.com/JayDataEngineer/melite-utility-nodes.git
```

Restart ComfyUI.
